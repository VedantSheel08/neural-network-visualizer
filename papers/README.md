# Papers

The research behind what's on the page. These are the actual papers the site
cites, kept here so the links never rot.

- **mnist-lecun-1998.pdf** — LeCun, Bottou, Bengio & Haffner, *Gradient-Based
  Learning Applied to Document Recognition* (1998). The MNIST paper, and where
  convolutional networks took off.
- **relu-nair-hinton-2010.pdf** — Nair & Hinton, *Rectified Linear Units
  Improve Restricted Boltzmann Machines* (ICML 2010). Where ReLU proved itself.
- **deep-sparse-rectifiers-glorot-2011.pdf** — Glorot, Bordes & Bengio, *Deep
  Sparse Rectifier Neural Networks* (AISTATS 2011). Why ReLU makes deep nets
  trainable.
- **adam-kingma-ba-2014.pdf** — Kingma & Ba, *Adam: A Method for Stochastic
  Optimization* (2014). The optimizer `train.py` uses.
- **dropout-srivastava-2014.pdf** — Srivastava, Hinton, Krizhevsky, Sutskever
  & Salakhutdinov, *Dropout* (JMLR 2014). The classic regularization trick.
- **attention-is-all-you-need-vaswani-2017.pdf** — Vaswani et al., *Attention
  Is All You Need* (2017). The transformer paper, for the "is chatgpt just a
  bigger version of this?" section.

All of these are publicly available from arXiv, JMLR, or the authors' own
pages; they're collected here unmodified.
